Partie théorique (5 minutes)
Dans un fichier notes.txt, répondre brièvement :

1. Définis ce qu’est un token en 1–2 phrases :

Un tokken est une méthode permettant de transformer du texte en nombres, permettant ainsi de mieux traiter l'information pour l'IA

EX : J'aime les fruits
Découpage : "J" "'" "aime" "les" "fruits"

On a un découpage en 5 Tokkens différents

2. Donne un exemple où un mot ≠ un token (ex : « aujourd’hui »).

J'adore est un exemple de 3 Tokkens différents pour un moment unique

3. Pourquoi un modèle IA a-t-il besoin de découper en tokens avant de lire une phrase ?

Car il permet de transformer l'information en chiffes, permettant ainsi de mieux identifier les requêtes car c'est plus simple de bosser avec des chiffres pour la machine.
